Task3: Nesting Block in Inline

Try placing a <div> inside a <span> element.

What error or layout issue do you see? Why does this happen?
Answer: putting a <div> element inside <span> around the text changed the whole thing to a block element instead of an inline element, changing the background color to match the block designated color, and the width spans the whole page. I think this happens because the <div> block element overrides the <span> inline element.
